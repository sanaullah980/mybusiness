# Android Firebase registration

This project is wired to the existing Firebase project `mybusinessapp-4734c`.

Before production Android Google Sign-In, register Android package `com.mybusiness.pos` in the existing Firebase project and add the SHA-1/SHA-256 fingerprints of the signing key. Download the generated `google-services.json` from Firebase Console and replace `android/app/google-services.json`.

Do not create a new Firebase project.
